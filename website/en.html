QGap encrypts every message with a one-time pad – the only encryption method that is mathematically proven to be unbreakable. Use it fully offline: transfer messages via animated QR codes, no internet involved.

🔑 One-time pad (OTP)

Every byte of your message is encrypted with a byte from a random key file that is never reused. Without the key file, the ciphertext is provably worthless – to any attacker, any supercomputer, any AI.

📵 Air gap: zero internet

Key exchange happens hand-to-hand via USB stick. Messages can be transferred as animated QR codes from screen to camera – your device never needs to go online. No cloud, no servers, no traces.

🤖 Not readable by AI

A one-time-pad ciphertext contains no exploitable patterns whatsoever. No language model and no analysis software can reconstruct or store content from the transmitted data.

☁️ Online if you choose

Optionally, chats can be synced through a cloud transport – messages remain end-to-end OTP-encrypted. The server only ever sees random bytes.

🛡️ Hybrid encryption (RSA + AES)

No in-person key exchange possible, or too much effort? Then QGap offers a proven hybrid scheme as an alternative: content is encrypted with AES-256-GCM, and the random AES key with the recipient's RSA-2048 key. Chat securely right away – without handing over a one-time-pad key file first.

🔍 Open source

The source code of the QGap core – including all of the encryption – is available as free software under the AGPLv3. Anyone can audit it – trust through transparency, not promises.

💻 Android + Windows

Full functionality on Android phones and Windows PCs. Messages, files, voice messages, invitations – the same experience everywhere.

📽️ Presentations: your projector substitute

Create presentations with song lyrics and images and show them on any screen with a browser – perfect on the go when no projector is available. Share control via QR code with multiple admins: everyone can advance slides, pick songs and display images right from their own phone.

Who is QGap for?

QGap is for everyone who wants to communicate freely – without anyone, any AI or any corporation being able to read along:

  • Businesses: trade secrets, negotiations and internal coordination stay internal – no need to trust third-party servers or cloud providers.
  • Journalists and reporters: protecting sources and research, even under surveillance pressure.
  • Government agencies and organisations: confidential communication with verifiable, auditable technology instead of a black box.
  • People in unsafe environments: wherever networks are monitored or devices may be compromised.

The decisive advantage: encryption and decryption can run on a device that is never connected to the internet – the message only crosses the gap (air gap) as a QR code. This defeats spyware, trojans, keyloggers and screen-capture malware alike: on the online device, the plaintext simply does not exist – all that can be seen there is unreadable ciphertext.

How it works

  • 1. Generate a key file: QGap creates a random key file (e.g. 20 MB – enough for thousands of messages).
  • 2. Exchange keys in person: the file is handed to your chat partner on a USB stick – never over the network.
  • 3. Write & encrypt: each message consumes a section of the key that is never used again.
  • 4. Transfer your way: via animated QR code (100% offline), as a file (USB/any channel), or optionally through the cloud.
